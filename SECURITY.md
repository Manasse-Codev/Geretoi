# Sécurité

DayFlow traite des tâches personnelles. Pour signaler une vulnérabilité, contactez le mainteneur du dépôt en privé (fonction « Report a vulnerability » de GitHub si disponible) et fournissez les étapes de reproduction, l’impact et une preuve minimale. N’incluez aucune donnée réelle d’utilisateur.

Le périmètre inclut le client web, les règles Firestore du dépôt, les exports et les configurations Vercel/Cloudflare. Les services Firebase réels, comptes tiers, domaines d’hébergement et dépendances upstream sont hors périmètre d’autorisation pour les tests. Utilisez uniquement les émulateurs locaux. Ne publiez pas de détails exploitables avant coordination avec le mainteneur.

Voir [docs/SECURITY.md](docs/SECURITY.md) pour le modèle de menaces, les constats et les actions de durcissement.
